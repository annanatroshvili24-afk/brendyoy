# Платные услуги МФЦ Белозерского округа

Одностраничный сайт о платных услугах МБУ «МФЦ Белозерского муниципального округа»: прейскурант на 2026 год, запись на услугу, контакты и режим работы.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Основная версия сайта в фирменном стиле «Мои Документы» |
| `index-v2.html` | Вторая версия, другая палитра |
| `index-v3.html` | Третья версия: первая с жёлтым подвалом |
| `для WordPress.html` | Блок для вставки на сайт МФЦ (WordPress, блок «Произвольный HTML») |
| `img/logo.png` | Логотип для шапки |

## Как устроена запись

Сервера и базы данных нет. Форма собирает заявку в текст и открывает письмо в почте посетителя на адрес МФЦ. Персональные данные на сайте не хранятся.

## Как поменять цену

- `index.html`: массив `GROUPS` в скрипте внизу страницы, число `p`.
- `для WordPress.html`: атрибут `data-price` и текст в `mp-price` у нужной строки.
